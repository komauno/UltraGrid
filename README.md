# UltraGrid

ウルトラワイドモニターでのネット株取引に最適化した、Rectangle 系ウィンドウ分割アプリの強化版。**縦横それぞれ最大6分割（6×6）**のグリッド配置、**ドラッグで吸着するスナップピッカー**、**レイアウトプリセットの一括保存/呼び出し**、そして**グローバルショートカット**を備えたメニューバー常駐アプリの土台です。

macOS 13+ / Swift 5.9 / AppKit。ネイティブアプリなので Accessibility 権限を使って実ウィンドウを制御します。

---

## インストール（配布版を使う人向け）

1. [Releases](../../releases) から最新の `UltraGrid-x.y.z.zip` をダウンロードして展開し、`UltraGrid.app` を「アプリケーション」フォルダへ移動します。
2. このアプリは Apple の署名・公証を付けていないため、初回だけ macOS のセキュリティ確認を解除する必要があります。
   - `UltraGrid.app` をダブルクリック → 「開けません」と出たら、**システム設定 → プライバシーとセキュリティ** を開き、下の方の「"UltraGrid" は開発元を確認できないため…」の横の **「このまま開く」** を押します。
   - うまくいかない場合はターミナルで次を実行してから開いてください:
     ```bash
     xattr -dr com.apple.quarantine /Applications/UltraGrid.app
     ```
3. 初回起動時に **アクセシビリティ** の許可を求められます。システム設定 → プライバシーとセキュリティ → アクセシビリティ で UltraGrid を ON にすると、ウィンドウの配置ができるようになります。

> メニューバーに常駐します（Dock には出ません）。設定はメニューバーのアイコンから開けます。

## これは「動く土台」です

主要機能の実装が一通り入った、Xcode で開いてビルドできる状態のソース一式です。ここから機能追加・UI 調整をして育てていく前提の骨格になっています。ビルドは macOS + Xcode 環境で行ってください（このソースは macOS 上でのみコンパイルできます）。

---

## ビルド方法

### 方法A: XcodeGen で自動生成（推奨）

XcodeGen が `project.yml` から `.xcodeproj` を生成します。

```bash
brew install xcodegen        # 未インストールなら
cd UltraGrid
xcodegen generate            # UltraGrid.xcodeproj が生成される
open UltraGrid.xcodeproj
```

Xcode で ⌘R を押すとビルド＆起動します。

### 方法B: Xcode で手動プロジェクト作成

1. Xcode で新規 macOS App（AppKit App Delegate または SwiftUI どちらでも可）を作成
2. 生成された `AppDelegate.swift` / `main` 相当を削除
3. `Sources/UltraGrid/` 内の全 `.swift` をドラッグして追加
4. ターゲット設定で以下を反映
   - `Info.plist` の `LSUIElement = YES`（Dock 非表示のメニューバーアプリ）
   - Signing & Capabilities で **App Sandbox を無効**（他アプリのウィンドウ制御に必須）
   - `UltraGrid.entitlements` を Code Signing Entitlements に指定

## ショートカット一覧

接頭修飾は **⌃⌥（Control+Option）**。多くのアプリのショートカットと衝突しにくい組み合わせです。以下は**初期設定**で、すべて設定画面の「ショートカット」タブから自由に変更・追加できます。

| ショートカット | 動作 |
| --- | --- |
| `⌃⌥Space` | **スナップピッカー**を表示（ドラッグでセル範囲を選んで吸着） |
| `⌃⌥←` / `⌃⌥→` | 左半分 / 右半分 |
| `⌃⌥↑` / `⌃⌥↓` | 上半分 / 下半分 |
| `⌃⌥Return` | 作業領域いっぱいに最大化 |
| `⌃⌥1` / `⌃⌥2` / `⌃⌥3` | 左 1/3 / 中央 1/3 / 右 1/3 |
| `⌃⌥⇧1` 〜 `⌃⌥⇧6` | 保存済み**プリセットの1〜6番目**を一括適用（固定） |

上記のうちプリセット呼び出し（`⌃⌥⇧1〜6`）以外は設定画面で編集できます。1/6幅の各列などが欲しい場合は「操作を追加」でゾーン（列/行/幅/高）とキーを割り当ててください。

## ドラッグスナップ（⌃⌥ を押しながら掴む）

`⌃⌥` を押しながらウィンドウをドラッグすると、離した位置のゾーンへ吸着します。ドラッグ中は画面にグリッドが薄く重なり、吸着先が半透明の白でハイライトされます。

- **⌃⌥ だけ**でドラッグ → ポインタ直下の**単一セル**に吸着（掴んだ元セルは含まれません）。
- ドラッグ中にさらに **⌘ を押している間だけ範囲選択モード**になります。⌘ を押した瞬間のセルを基準に、そこから現在ポインタのセルまでの矩形が選択範囲になります（⌃⌥Space のピッカーと同じ操作感）。例えば ⌘ を押した位置から中段3列目までドラッグすれば 3×2 の領域に吸着します。左半分・上半分・四分割なども ⌘ を押しながら範囲を広げれば作れます。
- **⌘ を離す**と単一セルモードに戻ります。**⌃⌥ を離す**とキャンセルします。

オン/オフは設定画面で切り替えられます。文字選択や通常のウィンドウ移動とは（⌃⌥ の有無で）はっきり区別されるため誤爆しません。

## 設定画面

メニューバーの ▦ →「設定…」（または `⌘,`）で開きます。3つのタブがあります。

- **一般**: ドラッグスナップのオン/オフ、ログイン時に起動、ウィンドウ間の隙間・画面端の余白（px）。
- **グリッド**: 分割数（横=列 / 縦=行、各 1〜6）。ピッカーとドラッグスナップで使われます。
- **ショートカット**: クイック操作の一覧を編集。各操作の名前・メニュー表示・配置（列/行/幅/高）・ショートカットキーを変更でき、操作の追加/削除、既定に戻すも可能。ショートカット欄をクリックしてキーを押すと記録されます（ESCで取消、×で解除）。

変更は即座に保存され、ホットキーとメニューにすぐ反映されます。設定は `~/Library/Application Support/UltraGrid/settings.json` に保存されます。

## スナップピッカーの使い方

`⌃⌥Space` を押すと、カーソルのあるスクリーンに 6×6 グリッドが半透明で重なります。**セルをドラッグで囲んで離す**と、最前面ウィンドウがその範囲にぴったり吸着します。`ESC` でキャンセル。

チャート1枚を左3×6、板情報を中央2×6、ニュースを右1×6…といった配置をマウスだけで直感的に組めます。

## レイアウトプリセット

- メニューの「**現在の配置を保存…**」で、いま開いている全ウィンドウの配置を最も近いグリッドに丸めて 1つのプリセットとして保存します（例: 「寄り付き用」「監視用」）。
- メニューやショートカット `⌃⌥⇧1〜6` で一括復元。バンドルID（無ければアプリ名）でウィンドウを識別します。
- 保存先: `~/Library/Application Support/UltraGrid/presets.json`（JSON なので手編集・バックアップも可能）

## 設計上のポイント

- **座標系**: AppKit（左下原点）と Accessibility（主ディスプレイ左上原点）の変換を `Geometry` に集約。ウルトラワイド + 複数モニタでのズレを防ぐ要。
- **グリッド原点は左上**: `row 0` が画面上端。人間の直感に合わせています。
- **隙間・外周余白**: `GridModel.gap` / `outerMargin` で調整可能。0 にすればぴったり敷き詰め。
- **メニューバー常駐**: `LSUIElement` + `.accessory` で Dock アイコンなし。

## 次に伸ばすと良い方向（ロードマップ）

1. **プリセットへのショートカット個別割当と管理 UI**: 現在プリセットは `⌃⌥⇧1〜6` 固定。設定画面のアクションと同様に任意キー割当・並べ替えできるようにする。
2. **ドラッグスナップの範囲選択**: 現在は端=半分・内側=単一セル。ドラッグ中に数字キーで複数セル幅を指定するなど、より細かい吸着に拡張。
3. **スクリーン指定の強化**: プリセットに物理配置（解像度変化への追従）を持たせる。マルチモニタでのゾーン指定 UI。
4. **配置のアニメーション**とマルチウィンドウの並列適用最適化。
5. **ログイン起動の署名対応**: `SMAppService` は署名済み・正規の場所にある .app で確実に動作します（下記「注意」参照）。

## 注意

- ソースは macOS + Xcode でのみビルドできます（AppKit / Carbon / Accessibility は macOS 専用）。
- App Sandbox は**無効**にする必要があります（サンドボックス内からは他アプリのウィンドウを操作できないため）。配布時は Developer ID 署名 + notarization を検討してください。
- 一部アプリ（サイズ制約の強いもの、非標準ウィンドウ）は Accessibility 経由のリサイズに完全には応じないことがあります。

# UltraGrid

Rectangle 系ウィンドウ分割アプリの強化版。**縦横それぞれ最大6分割（6×6）**のグリッド配置、**ドラッグでスナップするスナップピッカー**、**レイアウトプリセットの保存/呼び出し**、そして**ショートカットキー**を備えたメニューバー常駐アプリです。

macOS 13+ / Swift 5.9 / AppKit。ネイティブアプリなので Accessibility 権限を使って実ウィンドウを制御します。

---

## インストール（配布版を使う人向け）

1. [Releases](../../releases) から最新の `UltraGrid-x.y.z.zip` をダウンロードして展開し、`UltraGrid.app` を「アプリケーション」フォルダへ移動します。
2. このアプリは Apple の署名・公証を付けていないため、初回だけ macOS のセキュリティ確認を解除する必要があります。
   - `UltraGrid.app` をダブルクリック → 開けない旨のアラートが出たら、**システム設定 → プライバシーとセキュリティ** を開き、下の方の「"UltraGrid" は開発元を確認できないため…」の横の **「このまま開く」** を押します。
   - うまくいかない場合はターミナルで次を実行してから開いてください:
     ```bash
     xattr -dr com.apple.quarantine /Applications/UltraGrid.app
     ```
3. 初回起動時に **アクセシビリティ** の許可を求められます。システム設定 → プライバシーとセキュリティ → アクセシビリティ で UltraGrid を ON にすると、ウィンドウの配置ができるようになります。

> メニューバーに常駐します（Dock には出ません）。設定はメニューバーのアイコンから開けます。

---

## 初回起動時のセットアップ

1. アプリを起動するとメニューバーに ▦ アイコンが表示されます。
2. **システム設定 > プライバシーとセキュリティ > アクセシビリティ** で UltraGrid を許可
   （メニューの「⚠︎ アクセシビリティ権限が必要です」からも開けます）
3. 許可後、ショートカットとメニューが使用できるようになります。

## ショートカットキーの一覧

以下は初期設定で、すべて設定画面の「ショートカット」タブから変更・追加することができます。

| ショートカット | 動作 |
| --- | --- |
| `⌃⌥Space` | **スナップピッカー**を表示 |
| `⌃⌥←` / `⌃⌥→` | 左半分 / 右半分 |
| `⌃⌥↑` / `⌃⌥↓` | 上半分 / 下半分 |
| `⌃⌥Return` | 最大化 |
| `⌃⌥1` / `⌃⌥2` / `⌃⌥3` | 左 1/3 / 中央 1/3 / 右 1/3 |
| `⌃⌥⇧1` 〜 `⌃⌥⇧6` | 保存済み**プリセットの1〜6番目**を適用（固定） |

上記のうちプリセットの呼び出し（`⌃⌥⇧1〜6`）以外は設定画面で編集できます。

## ドラッグスナップ（⌃⌥ を押しながらウィンドウをドラッグ）

`⌃⌥` を押しながらウィンドウをドラッグすると、離した位置のグリッドにスナップします。ドラッグしている間は画面にグリッドが表示され、スナップするグリッドがハイライトされます。

- **⌃⌥ だけ**でドラッグ → **単一のグリッド**にスナップします。
- ドラッグ中にさらに **⌘ を押している間は、スナップするグリッドの範囲を選択**できます。
- **⌃⌥ を離す**とキャンセルします。


## 設定画面

メニューバーの ▦ →「設定…」（または `⌘,`）で開きます。

- **一般**: ドラッグスナップのオン/オフ、ログイン時に起動、ウィンドウ間の隙間・画面端の余白（px）。
- **グリッド**: 分割数（横方向 / 縦方向、各 1〜6）。ピッカーとドラッグスナップで使われます。
- **ショートカット**: クイック操作の一覧を編集します。各クイック操作の名前・メニュー表示・配置・ショートカットキーを変更できます。

クイック操作の設定は `~/Library/Application Support/UltraGrid/settings.json` に保存されます。

## スナップピッカーの使い方

`⌃⌥Space` を押すと、6×6の グリッドが表示されます。**グリッドをドラッグで囲んで離す**と、最前面ウィンドウがその範囲にスナップします。`ESC` でキャンセル。

---

## レイアウトプリセット

- メニューの「**現在の配置を保存…**」で、いま開いている全ウィンドウの配置をプリセットとして保存します。
-  **保存済みプリセットの1〜6番目**は`⌃⌥⇧1〜6`で呼び出すことができます。
- 保存先: `~/Library/Application Support/UltraGrid/presets.json`

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `main.swift` | エントリポイント（メニューバー常駐） |
| `AppDelegate.swift` | ライフサイクル + 設定に基づくホットキー登録 |
| `Settings.swift` | 設定モデル・永続化・ログイン起動・アクション/ショートカット定義 |
| `Models.swift` | グリッド仕様・領域・プリセットのデータ型 |
| `Geometry.swift` | AppKit ⇔ Accessibility の座標変換 |
| `GridModel.swift` | 6×6 グリッドの矩形計算（隙間・余白対応） |
| `WindowController.swift` | Accessibility API によるウィンドウ移動/リサイズ |
| `HotkeyManager.swift` | Carbon によるグローバルホットキー |
| `PresetStore.swift` | プリセットの保存/復元（JSON 永続化） |
| `SnapOverlay.swift` | スナップピッカー（ドラッグ範囲選択）のオーバーレイ UI |
| `DragSnapMonitor.swift` | ⌃⌥ ドラッグスナップの監視・オーバーレイ・ゾーン解決 |
| `SettingsWindow.swift` | 設定画面（SwiftUI）＋キーレコーダ |
| `MenuBarController.swift` | メニューバー UI とアクション |
| `Accessibility.swift` | 権限確認・要求 |


---

## 注意

- ソースは macOS + Xcode でのみビルドできます（AppKit / Carbon / Accessibility は macOS 専用）。
- App Sandbox は**無効**にする必要があります（サンドボックス内からは他アプリのウィンドウを操作できないため）。配布時は Developer ID 署名 + notarization を検討してください。
- 一部アプリ（サイズ制約の強いもの、非標準ウィンドウ）は Accessibility 経由のリサイズに完全には応じないことがあります。
